# Отчёт: Telegram-уведомления нескольким менеджерам

## Изменения
- Настройка `chatIds` (до 30 уникальных ID) в существующем JSON конфигурации: миграция БД не нужна.
- В админке список Chat ID, по одному ID на строку; прежний `chatId` отображается и поддерживается.
- Новые заявки и тестовое сообщение отправляются всем уникальным получателям параллельно.
- Отказ одного получателя не препятствует отправке другим; ошибка доступна в статусе уведомления.

## Проведённые тесты
Команда: `node tools/test-telegram-multi.cjs`.
Результат: **PASS, 9 проверок**: 5 транспиляций TypeScript/TSX и 4 проверки списка/рассылки (устранение дублей, успех всем, частичный отказ, пустой список).

## Не удалось подтвердить
- `npm ci` не завершился в тестовой среде; `tsc -b packages/web/tsconfig.json` завершился ошибкой из-за недоустановленных типов (например, babel__core, bun). Полноценные сборка, линтер и тесты БД **не пройдены**.
- Сквозной тест на реальном Telegram, SMTP, платежах, CAPTCHA и хостинге не выполнялся: нет доступа к токенам, БД и рабочему серверу.
- Общее качество/готовность к продакшену всего функционала не подтверждены.

## Известное ограничение
Если 2 из 3 менеджеров получили сообщение, а третий — нет, повторная попытка отправит сообщение всем троим: уже получившие могут получить дубль. Для гарантии без дублей нужна отдельная таблица состояний отправки на каждого получателя и миграция БД.

## Как установить
1. Создайте резервные копии текущей версии и базы данных.
2. Замените исходники на сервере, сохраните действующий `.env`, пользовательские загрузки и БД.
3. Установите зависимости и выполните `npm run build:web` на сервере с рабочим Bun/Node и lockfile.
4. Перезапустите **фактический** PM2-процесс: `pm2 restart asia --update-env` (если название `asia`; в комплектном `ecosystem.config.cjs` процесс называется `web-app`).
5. В админке → «Заявки / Telegram» заполните Chat ID менеджеров (каждый с новой строки), сохраните настройки, затем запустите «Тест Telegram». Каждый менеджер обязан сначала нажать Start у бота.
6. Прогоните тестовую заявку и убедитесь, что она видна в админке и пришла всем менеджерам.

## Безопасность
Telegram-бот токен по-прежнему берётся только из переменной `TELEGRAM_BOT_TOKEN`, не из браузера. Не добавляйте рабочий `.env` в архив/репозиторий.
